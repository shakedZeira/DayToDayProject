### 2. NBA games — no games shown (fixed)
- Root cause: only game source was `NbaBigBallsClient`
  (`https://api.bigballsdata.com/v1/nba`) which sends no auth header — verified
  live **HTTP 401**. The ESPN fallback `NbaRepositoryImpl.fetchEspnScoreboard`
  was a stub returning `Result.success(emptyList())`, and because that is a
  *success*, the demo-game seeding never ran either → empty screen.
- `NbaEspnClient.getScoreboard(date)` added against
  `https://site.api.espn.com/apis/site/v2/sports/basketball/nba/scoreboard?dates=YYYYMMDD`
  (verified live: 4 games for 20261006). `espnDate()` passes `"today"` through
  and strips dashes from `yyyy-MM-dd`.
- Also: BBS 401 returns valid JSON with no `data` key, which produced a
  *successful* empty list that short-circuited before ESPN. BBS now only wins
  when it returns a non-empty list; ESPN failure propagates as `Result.failure`
  so demo seeding can fire.
- New DTOs `EspScoreboardGame` / `EspScoreboardTeam`, mapped to `NbaGame`/`NbaTeam`.

### 3. NBA injuries — team filter did nothing (fixed)
- `NbaInjuriesScreen` had 8 hardcoded chips passing **abbreviations** (`"LAL"`),
  but `InjuryEntity.teamId` is the **numeric ESPN id** (`teamRoot["id"]`), so
  `WHERE teamId = 'LAL'` matched zero rows.
- `fetchInjuriesFromApi(teamId)` also cached only the single-team subset,
  corrupting the cache on every filtered load. It now always caches the full
  ESPN set and filters only the returned list.
- Filtering now happens client-side in `NbaInjuriesViewModel` via
  `Injury.matchesTeamFilter(token)` (matches teamId / name equality / name
  contains), and chips are derived from the loaded data (`teams: StateFlow`,
  sorted, de-duped) instead of a hardcoded list.

### 4. NBA news — no photo previews (fixed)
- Root cause: **Coil 3 ships without network support.** Only
  `io.coil-kt.coil3:coil-compose:3.0.4` is declared; without
  `coil-network-okhttp`/`coil-network-ktor2` there is no fetcher for `https:`,
  so `SubcomposeAsyncImage` always lands in the `error` slot → the grey slab.
  Confirmed by dex-scanning the built APK: `coil3/SingletonImageLoader` present,
  `coil3/network` absent.
- `NbaNewsScreen` now downloads images itself (`downloadNewsImage` with OkHttp on
  `Dispatchers.IO`, LRU of 8, `BitmapFactory` downsample to 1080px) and renders
  via `Image`. Failure renders **nothing** (compact card) instead of a grey box.
- Import bug fixed: it imported `com.squareup.okhttp3.*` (the Maven *group id*)
  instead of the `okhttp3.*` package — that was a compile error.
- `EspNewsArticle.imageUrl` now uses `firstNotNullOfOrNull` over `images`.
- **Still open:** `GameCard.kt:128` and `NbaGameDetailScreen.kt:237` still use
  Coil for remote URLs and will stay broken until either
  `implementation("io.coil-kt.coil3:coil-network-okhttp:3.0.4")` is added at
  `composeApp/build.gradle.kts:62`, or they are ported to `NewsImage`-style
  loading. Adding the Coil artifact is the better fix.
